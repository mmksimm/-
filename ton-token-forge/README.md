# TON Token Forge

Telegram Mini App to quickly create and mint Jetton tokens on the TON blockchain.

## Development

```bash
npm install
npm run dev
```

Run the dev server and open the app through Telegram by adding the URL as a Web App for your bot. The UI adjusts to Telegram's theme via `telegram-web-app.js`.

The manifest for TON Connect is located at `public/tonconnect-manifest.json`.
