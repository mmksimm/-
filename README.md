# Multi Project Deployment

This repository contains multiple Telegram mini-app prototypes.

- **Memhash** static demo (root `index.html`).
- **Gang War** prototype (`gang.html`).
- **TON Forge** React application (`ton-forge` directory).

GitHub Actions builds the React app and deploys all projects to GitHub Pages. The `ton-forge`
app is served from `/ton-forge/` on the Pages site.
